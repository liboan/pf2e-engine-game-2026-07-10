## Counter Performance findings and pending decisions

Astra's bounded source investigation found that [Fear](https://2e.aonprd.com/Spells.aspx?ID=1524) lacks auditory/visual traits; casting speech does not make it eligible. [Dizzying Colors](https://2e.aonprd.com/Spells.aspx?ID=1500) is a source-valid visual trigger with a 15-foot cone, Will saves and dazzled/blinded/stunned consequences. Rank 1 against level-1–2 targets avoids the [incapacitation](https://2e.aonprd.com/Traits.aspx?ID=631) upgrade. This is proposed encounter content, not verified engine support.

[Counter Performance](https://2e.aonprd.com/Spells.aspx?ID=1762) substitutes a result. The [check rules](https://2e.aonprd.com/Rules.aspx?ID=2283) define result as die plus modifiers, while [natural-die degree adjustments](https://2e.aonprd.com/Rules.aspx?ID=2286) are separate. Astra found no authoritative specific clarification determining which natural die applies to the borrowed total. The structured user question offers A, numeric substitution with the beneficiary's original natural-die adjustment (recommended as closest to the wording), or B, independently resolve each candidate with its own die and take the better outcome. Neither is silently treated as settled printed law.

At DC 20, source-grounded distinguishing examples are:

| Original save; Performance | A: original save die | B: each candidate's die |
|---|---|---|
| 1+7=8; 15+7=22 | Failure | Success |
| 12+7=19; 20+7=27 | Success | Critical success |
| 16+5=21; 11+7=18 | Success | Success |

The second structured question proposes pausing after the triggering save and before consequences, selecting one fortune route per beneficiary before extra dice, then rolling the Bard's Performance. [Fortune](https://2e.aonprd.com/Traits.aspx?ID=612) limits a roll to one fortune effect, so the same save cannot receive both Counter Performance and a Hero Point reroll. Treating the Bard's Performance as a separate check eligible for the Bard's own Hero Point is a proposed per-roll interpretation; the exact competing-fortune selection order is not explicitly specified. An ally cannot spend their point on the Bard's roll. [Hero Points](https://2e.aonprd.com/Rules.aspx?ID=2333) require retaining the second result: Performance 15+7=22 rerolled to 4+7=11 must retain 11; an ally with 16+5=21 can still keep their own save. Await the user's timing decision before dependent work.

Keep separate check owner, die, total and fortune records in the existing continuation/choice state. No new general framework is required by these findings. Root has only summarized Astra's findings and has not read the sources or implementation.
